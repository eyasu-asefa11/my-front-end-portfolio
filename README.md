# Portfolio Website

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript, featuring a clean design with Tailwind CSS and interactive animations.

## 🚀 Project Overview

Throughout our collaboration, we successfully transformed a template portfolio into your personalized professional website. The project began with initial setup and dependency installation, followed by extensive customization to reflect your personal brand and contact information.

## ✨ Features

### Core Features
- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, modern design with purple gradient theme and smooth animations
- **Interactive Navigation**: Smooth scrolling navigation with active section highlighting
- **Mobile Menu**: Hamburger menu for mobile devices
- **Contact Form**: Functional contact form with validation and user feedback

### Advanced Features
- **Scroll Animations**: Fade-in animations triggered by scroll position
- **Skill Bars**: Animated progress bars that fill when scrolled into view
- **Typing Effect**: Dynamic typing animation on the hero section
- **Parallax Scrolling**: Subtle parallax effect on the hero section
- **Dark Mode Toggle**: Optional dark/light theme switcher
- **Scroll-to-Top Button**: Convenient button for quick navigation to top
- **Hover Effects**: Interactive hover effects on project cards and buttons

## 🛠️ Technologies Used

### Frontend
- **HTML5**: Semantic HTML structure
- **CSS3**: Modern CSS with custom animations and transitions
- **Tailwind CSS**: Utility-first CSS framework for rapid styling
- **JavaScript (ES6+)**: Modern JavaScript for interactivity
- **Font Awesome**: Icon library for social media and UI icons

### External Dependencies
- **Tailwind CSS CDN**: For styling
- **Font Awesome CDN**: For icons
- **Google Fonts**: Inter font family

## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Local web server (optional, for development)

### Installation
1. Clone or download the project files
2. Navigate to the project directory
3. Open `index.html` in your browser or run a local server

### Running Locally
```bash
# Using Python
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Or simply open index.html in your browser
```

## 🎨 Customization Guide

### Personal Information
- Update your name in the hero section (line 65 in `index.html`)
- Replace placeholder email and contact information
- Add your actual social media links

### Profile Image
- Replace the placeholder image URL in the About section
- Recommended size: 400x400px for optimal display

### Projects
- Update project titles, descriptions, and technologies
- Replace placeholder images with actual project screenshots
- Add live demo and repository links

### Skills
- Adjust skill percentages to match your proficiency
- Add or remove skills as needed
- Update skill categories (Frontend, Backend, Design Tools)

### Color Scheme
- Modify the purple gradient colors in the CSS
- Update hover states and accent colors
- Adjust dark mode colors if needed
